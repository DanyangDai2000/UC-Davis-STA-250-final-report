# ADHD 脑功能连接中的独立判别信号：一项相关性与因果性的统计考察

> 数据：WiDS Datathon 2025（HBN 儿童脑影像队列）
> 研究问题：脑功能连接（相关结构）里到底有没有独立于问卷的判别信号？如果有，多大？
> 方法：图卷积网络（GCN）+ 多层对照基线（逻辑回归 / 梯度提升 / 图论特征 / 偏相关）
> 核心关切：**预测（相关）与解释（因果）的边界**

---

## 摘要

本报告回答一个统计问题：**在防泄漏、类不平衡、水位基线都得到控制的
条件下，脑功能连接（相关结构）里到底有没有独立于问卷的判别信号？
如果有，多大？** 用 1,213 名受试者的 200 脑区功能连接矩阵，配合图卷积
网络（GCN）与多层对照基线，把这个信号追到底。

结论是分层的，而且关键之处不在模型，而在数据的统计学性质：

1. **功能连接矩阵是相关性数据，不是因果结构。** 它描述的是脑区活动在
   受试者间的同步程度（Pearson 相关），本身无方向、无干预含义。
2. **预测力强 ≠ 因果。** 行为问卷（SDQ 多动量表）单独就能给出
   ROC-AUC 0.84 的分类，但这部分是「定义性相关」——SDQ 本身就是 ADHD
   诊断评估工具的一部分，用它预测诊断标签近似循环。
3. **连接矩阵单独几乎无信号**（GCN AUC 0.555、梯度提升 0.505，均接近
   随机），加在问卷之上只带来 +0.017 的增量。
4. **六项统计迭代（§5）进一步确认**：图结构相对扁平特征有 +0.05 的稳定
   显著增量（bootstrap，p=0.002）；去批次协变量只贡献 +0.010；偏相关
   （去全局混淆）把连接矩阵 AUC 从 0.511 提到 0.536；可解释图论特征也
   只有 0.527；中介分析显示连接模式**不是**问卷→诊断的中介（间接效应
   ≈0）。连接矩阵的「独立信号」即便榨到极限，也只有微弱的一点点。

因此，本报告的核心结论不是「GCN 能不能分类 ADHD」，而是：**在把
「统计关联」误读为「因果机制」之前，先回答数据本身是什么。** 功能
连接是关联的载体，不是机制的证明。

## 1. 引言与数据

### 1.1 引言

注意缺陷多动障碍（ADHD）是儿童期最常见的神经发育障碍之一。静息态
功能磁共振（rs-fMRI）让研究者能以无创方式刻画脑区之间的功能连接，
由此形成一个核心假设：ADHD 的病理可能体现为脑网络拓扑结构的系统性
改变。随着图神经网络（GNN）的普及，大量工作尝试把功能连接矩阵直接
输入图模型，以期从「脑网络」层面做出更准确的诊断，或挖掘可解释的
生物学标志物。

但这一研究范式隐含一个常被忽视的区分：**功能连接度量的是脑区活动在
时间上的统计相关（Pearson 相关），它本身不带方向信息，也不等价于
因果结构。** 一个模型在连接矩阵上取得高分类精度，只能说明「连接模式
与诊断标签之间存在可预测的关联」，不能说明「脑网络改变导致了 ADHD」。
当预测变量里还包含问卷量表这类与诊断标准在构造上重叠的特征时，高精度
甚至可能退化为一种循环论证——模型学到的是诊断定义的翻版，而不是疾病
机制。

现有基于 WiDS 2025 ADHD 竞赛数据的工作，多数把目标设定为「最大化分类
性能」，但对两个更基本的问题回答不足：第一，在严格控制数据泄漏、类别
不平衡与批次效应之后，功能连接矩阵里是否还存在独立于问卷元数据的判别
信号？第二，如果存在，这个信号的量级有多大、方向是否稳定？

因此，本研究不追求最高的分类精度，而是把研究问题明确为：**在防泄漏、
类不平衡、水位基线都得到控制的条件下，脑功能连接（相关结构）中到底
有没有独立于问卷的判别信号？如果有，多大？** 与之对应，目标有三：
① 用 subject-level 切分与加权 F1 建立可信的评估口径，避免「阳性多数类」
造成的假高分；② 以多层对照基线（逻辑回归、梯度提升、GCN、可解释图论
特征、偏相关）定位信号来源；③ 用 bootstrap 显著性检验与中介分析，进一步
回答「图结构增量是否稳定」与「连接模式是否构成问卷→诊断的中介路径」。

结果显示，行为问卷（SDQ_Hyperactivity）几乎承载了全部判别信号（逻辑
回归 AUC 0.840），而功能连接矩阵单独几乎无法区分 ADHD（GCN 0.555、
扁平基线 0.505）；图结构带来的增量虽统计显著（+0.052，Wilcoxon
p=0.002），但绝对量很小；偏相关去混淆后信号仅从 0.511 升至 0.536；
中介分析表明连接模式**不是**问卷→诊断的中介。本研究的方法论贡献不在于
提出一个更强的模型，而在于示范一套「不自我欺骗」的评估口径，并把
「相关」与「因果」的边界显式化：**功能连接是关联的载体，不是机制的
证明；预测做得好，不等于因果讲得通。**

### 1.2 数据

| 项 | 值 |
|---|---|
| 样本量 | 1,213 名受试者 |
| 标签分布 | ADHD 阳性 831（68.5%），对照 382（31.5%） |
| 核心输入 | 每人一张 **200 × 200 脑区 Pearson 功能连接矩阵**（上三角 19,900 维） |
| 元数据 | 定量（EHQ 执行功能 / 色觉 / APQ 教养 / SDQ 行为 / 年龄）+ 分类（站点 / 种族 / 扫描地 / Barratt 社会经济地位） |

两个与统计学直接相关的性质，在开篇就必须说清：

- **类别不平衡是「阳性为多数」**。这与常见的「罕见病少数类」相反：直接
  猜「全部阳性」就有 68.5% 的准确率。因此**准确率在此是欺骗性指标**，
  本报告改用加权 F1 与 balanced accuracy 作为主指标（见 §2.2、附录 A）。
- **功能连接 = Pearson 相关**。输入矩阵的每个元素是两个脑区时间序列的
  相关系数。它只回答「两个脑区是否同步变化」，不回答「谁驱动谁」。

## 2. 方法

### 2.1 建模

把每个受试者表示成一张固定 200 节点的图：

- **节点**：200 个脑区（ROI）；
- **边**：脑区间功能连接，权重取 `|Pearson 相关系数|`，保留每张图
  `|corr|` 最强的 top 10% 边（稀疏化以抑制过平滑），加自环后对称归一化
  `D^{-1/2} A D^{-1/2}`；
- **节点特征**：该脑区到全部脑区的连接指纹（200 维）+ 节点强度（1 维）。

分类器：两层 GCN + ReLU + 全局平均池化 + 二分类 logits（`torch` 手写，
无 torch-geometric 依赖）。GCN 的目的不是追求最高分，而是提供一个
「把连接矩阵当作**图结构**来用」的参照，与「把连接矩阵当作**扁平特征**」
的基线对比。

对照基线（用于定位信号来源）：

| 基线 | 输入 | 要回答的问题 |
|---|---|---|
| 多数类基线 | 无 | 水位：什么都不学能到多少 |
| 逻辑回归 | 元数据 | 只靠问卷能到多少 |
| 梯度提升 | 元数据 | 非线性地只靠问卷能到多少 |
| 梯度提升 | 仅连接矩阵（SVD 64 维） | 连接矩阵**单独**有无信号 |
| 梯度提升 | 元数据 + 连接矩阵 | 连接矩阵在问卷之上有无**增量** |
| GCN | 仅连接矩阵（图结构） | 图结构 vs 扁平特征，谁更能榨出信号 |

### 2.2 评估口径（统计严谨性所在）

1. **subject-level 切分，杜绝泄漏。** 每个受试者是一整张矩阵，必须整图
   进入训练集或测试集。绝不允许同一个受试者的脑区 / 连接边被拆到两侧，
   否则模型「背下」受试者身份，指标虚高。本报告用**分层 5 折交叉验证**。
2. **主指标 = 加权 F1**。因阳性是多数类，另报每类 F1、ROC-AUC、
   balanced accuracy 作交叉印证，不单看准确率。
3. **水位基线。** 用多数类基线与「只靠问卷」的基线，作为随机与简单信号
   的参照系，从而能回答「连接矩阵相对问卷到底加了多少」。
4. **归因 ≠ 因果。** SHAP（梯度提升 TreeExplainer）与 GCN 的梯度 × 输入
   节点显著度，只解释「模型在**预测意义**上更依赖哪些特征 / 脑区」，
   不构成任何因果声明（§4.3 展开）。

## 3. 结果

分层 5 折交叉验证（subject-level，无泄漏），完整指标：

| 模型 | 准确率 | 加权 F1 | macro F1 | F1(对照) | F1(ADHD) | ROC-AUC | balanced acc |
|---|--:|--:|--:|--:|--:|--:|--:|
| 多数类基线 | 0.685 | 0.557 | 0.407 | 0.000 | 0.813 | 0.500 | 0.500 |
| 逻辑回归（元数据） | 0.760 | 0.767 | 0.739 | 0.665 | 0.813 | **0.840** | 0.759 |
| 梯度提升（元数据） | 0.786 | 0.781 | 0.740 | 0.630 | 0.850 | 0.802 | 0.730 |
| 梯度提升（仅连接矩阵） | 0.645 | 0.574 | 0.455 | 0.133 | 0.777 | 0.505 | 0.494 |
| 梯度提升（元数据＋连接矩阵） | 0.791 | 0.782 | 0.738 | 0.620 | 0.856 | **0.819** | 0.723 |
| **GCN（仅连接矩阵）** | 0.580 | 0.587 | 0.531 | 0.379 | 0.683 | 0.555 | 0.533 |

### 三个发现

**发现一：多数类基线的准确率是 0.685，但加权 F1 只有 0.557、对照类
F1 为 0。** 这正是类别不平衡下准确率的欺骗性：模型「什么都没学」，仅靠
「全猜阳性」就拿到 68.5% 的准确率。这解释了为什么本报告不以准确率定
优劣。

**发现二：行为问卷是主信号。** 只靠元数据的逻辑回归 AUC 就达 0.840；
SHAP 归因中 `SDQ_Hyperactivity`（mean|SHAP| ≈ 3.0）是第二名（≈ 1.06）的
近三倍，前几名几乎全部是 SDQ 行为问卷与 APQ 教养问卷的维度。信号几乎
完全来自问卷，而非影像。

**发现三：连接矩阵单独几乎无信号，增量很小。** 仅用连接矩阵：GCN
AUC 0.555、梯度提升 0.505，都接近随机（0.500）；加在元数据之上，梯度
提升仅从 0.802 升到 0.819（+0.017）。这说明**图结构能多榨出一点信号，
但远不足以单独支撑分类**。

## 4. 统计学核心关切：相关性与因果性

这是本报告要着重讲清的部分。三个发现合起来指向同一个统计问题：**这里
的「强预测」究竟在多大程度上等于「真实的病因或机制」？** 答案是：几乎
不相等。下面分四层说清。

### 4.1 功能连接是「相关」，不是「因果」

输入矩阵的每个元素是 Pearson 相关系数。相关系数有三个无法绕开的性质：

1. **无方向**：`corr(X, Y) = corr(Y, X)`，无法区分「X 影响 Y」还是「Y
   影响 X」；
2. **对称**：它压缩掉了时间先后与作用方向；
3. **易被混淆**：两个脑区活动的同步，可能是真实神经耦合，也可能是
   **共同原因**（如全局信号、头动、呼吸 / 心跳等生理噪声同时抬高多个
   脑区），还可能是**反向因果**。

因此，功能连接矩阵回答的是「哪些脑区**一起变**」，而不是「哪个脑区
**驱动**哪个」。把它当作图（GCN 的邻接矩阵）来建模，是把它当作
**关联结构**在利用，并不能因此把它升级为**因果图**。这是一个关键边界：
**图神经网络里的「图」，是相关图，不是因果图。**

### 4.2 预测 ≠ 因果

分类器学习的是条件关联 `P(ADHD | 特征)`，目标是「在给定特征时把标签
猜对」。它不回答、也无法回答「干预某特征（例如降低某问卷分数）是否
改变 ADHD 结局」——后者需要 `E[Y | do(X)]` 意义上的因果量，需要
反事实框架、随机化或因果图（DAG）工具变量等，本报告没有、也不声称
在做这件事。

由 4.1 与 4.2 推出一个直接后果：**AUC 高不等于发现了机制。** 一个特征
预测力强，可能是因为它是病因，也可能是因为它是结局的**代理变量**
（proxy）或**共同结果**。下一节正是这个陷阱的实例。

### 4.3 SDQ_Hyperactivity 主导：一个「循环 / 构造性相关」的警示

SHAP 显示 `SDQ_Hyperactivity` 遥遥领先。但 SDQ（长处与困难问卷）的
多动量表本身就是 ADHD 临床评估的组成部分——诊断过程往往就在参考这类
行为量表。于是出现一个统计学上必须点破的现象：

> **用诊断标准的子项去预测诊断结果，测得的高相关在很大程度上是
> 定义性的，而不是发现性的。**

换言之，`SDQ_Hyperactivity` 与 `ADHD_Outcome` 的强相关，主要反映的是
**构造重叠**（construct overlap）——两个变量在定义上就共享同一套
行为描述。这更接近「循环论证」，而非「找到了 ADHD 的一个预测因子」。
这类特征的高 SHAP 值，是**预测意义上的贡献**，不能解读为**病因或
机制**。

同样要谨慎对待的是 `Basic_Demos_Enroll_Year`（入组年份）排第二——它
大概率反映的是数据采集批次 / 站点效应，是**混淆变量**而非机制。这再次
印证：预测贡献榜 ≠ 机制证据榜。

### 4.4 从「相关」到「因果」需要什么（本报告明确不做）

把本报告的关联结论升级为因果结论，至少需要补齐以下任一项：

- **干预 / 反事实**：对某脑区或行为做干预并观察结局变化；
- **因果图（DAG）**：显式画出混淆、中介、碰撞变量并据此调整；
- **工具变量 / 自然实验**：利用外部随机性切断混淆路径；
- **时间维度**：纵向数据区分「先发生」与「后发生」。

这些都需要本数据所不具备的设计要素（本数据是横断的、观察性的、相关性的）。
因此本报告**明确声明**：所有结论限于**关联与预测**层面，不做因果推断。
这本身就是一个统计结论——**承认「数据能支持什么、不能支持什么」，比
得到一个漂亮的 AUC 更重要。**

## 5. 统计迭代：六项检验

研究问题「脑网络里有没有独立于问卷的判别信号」不能只停在「GCN AUC 0.555」
一句话上。下面六项检验从**显著性、解剖、批次、混淆、可解释性、中介**六个
角度，把这个问题追到底。

### 5.1 图结构 vs 扁平特征：差距是否稳定显著（bootstrap）

「GCN 0.555 > 扁平 0.505」这 0.05 的差距，究竟是真信号还是随机波动？用
10 个随机种子分别重跑 GCN 与扁平 SVD-GBM（同一 subject-level 分层 5 折），
得到成对的 out-of-fold AUC：

| 指标 | 值 |
|---|---:|
| GCN 均值 AUC | 0.544 ± 0.017 |
| 扁平均值 AUC | 0.492 ± 0.021 |
| 差值均值（10 个种子全为正） | +0.052 |
| 差值 bootstrap 95%CI | [+0.043, +0.061] |
| Wilcoxon 符号秩检验 | p = 0.002 |
| 配对 t 检验 | p < 0.001 |

**图结构相对扁平特征有约 +0.05 的增量，方向在 10/10 个种子里一致，且
统计显著（p=0.002）。** 这坐实了「图结构确实能多榨出一点信号」，但绝对量
仍然很小——0.544 远低于问卷的 0.84。

### 5.2 GCN 显著脑区 → 解剖名（Schaefer 200）

把 GCN 的节点显著度从 ROI 编号映射到 **Schaefer 2018 200-parcel（7 networks）**
的解剖名（数据 ROI i ↔ 官方 parcel 编号 i+1）。前 50 个显著脑区的网络分布：

| 网络（Yeo 7 网络） | 显著脑区数 |
|---|---:|
| Default（默认模式网络） | 27 |
| Cont（额顶控制） | 9 |
| DorsAttn（背侧注意） | 8 |
| SomMot（感觉运动） | 3 |
| Vis（视觉） | 2 |
| Limbic（边缘） | 1 |

前 50 名集中在**默认模式网络、额顶控制、背侧注意**——这与 ADHD 文献高度
一致（默认模式网络异常是 ADHD 最一致的影像发现之一），反向印证了 ROI 顺序
假设成立。但必须诚实：GCN 的 AUC 只有 0.555（接近随机），这些 saliency 的
绝对值信号很弱，**不能**据此宣称「发现了 ADHD 的脑区」，只能作为
「显著性分布与已知网络相符」的弱佐证。

### 5.3 去批次 / 去站点协变量

`Basic_Demos_Enroll_Year` 在 SHAP 里排第二，疑似批次效应。去掉
`Enroll_Year` / `Study_Site` / `Scan_Location` 三个批次变量后重跑梯度提升：

| 输入 | ROC-AUC |
|---|---:|
| 完整元数据 | 0.806 |
| 去掉批次变量 | 0.797 |
| 批次贡献（Δ） | +0.010 |

结论：批次效应存在但很小，不影响「问卷主导」的主结论。`Enroll_Year` 的高
SHAP 主要来自与年龄等变量的共线，而不是独立信息。

### 5.4 偏相关（精度矩阵）替代 Pearson

Pearson 相关会被全局信号、间接连接共同抬高（§4.1）。数据未提供原始时间
序列，故用**精度矩阵 Theta = inv(R)** 近似偏相关（等价于高斯图模型下
「控制其余全部脑区」后的净相关）。SVD 降至 64 维后跑同一扁平基线：

| 连接矩阵 | ROC-AUC |
|---|---:|
| Pearson（SVD64） | 0.511 |
| 偏相关（SVD64） | 0.536 |

**去混淆后连接矩阵的信号反而更强了（+0.025）**，但绝对值仍远低于问卷
（0.84）。这支持 §4.1 的判断：Pearson 里的确有混淆成分，去掉后净信号
略有回升，但依然很弱。

### 5.5 可解释图论特征

从黑箱 GCN 转向网络科学的标准度量——全局效率、聚类系数、度中心性、
节点强度、特征向量中心性：

| 输入 | ROC-AUC |
|---|---:|
| 仅图论特征 | 0.527 |
| 元数据 + 图论特征 | 0.821（元数据单独 0.806，+0.015） |

单特征 AUC 全部落在 0.50–0.52 之间（全局效率 0.513、聚类系数 0.510、
特征向量中心性 0.522……），没有一个能独立分类。结论：**可解释的网络
度量与黑箱 GCN（0.555）水平相当，同样弱**——这反而说明「信号弱」是
数据本身的性质，不是 GCN 没调好。

### 5.6 中介分析 + DAG

显式建模「问卷 → 连接模式 → 诊断」。暴露 X = `SDQ_Hyperactivity`，中介
M = 全局效率（连接模式的标量代表），结局 Y = ADHD。用线性概率模型 +
bootstrap（5000 次）估计路径系数与间接效应：

| 路径 | 系数 |
|---|---:|
| a（SDQ → 连接模式） | −0.067 |
| b（连接模式 → ADHD ｜ SDQ） | +0.023 |
| c（总效应 SDQ → ADHD） | +0.258 |
| c′（直接效应） | +0.259 |
| **间接效应 a·b** | **−0.002**（95%CI [−0.004, 0.000]，不显著） |
| 中介占比 a·b / c | ≈ 0% |

加年龄协变量后结论不变（间接效应 −0.001，仍不显著）。**连接模式不是
问卷→诊断的中介**：SDQ 对 ADHD 的强相关几乎全部是「直接」的（构造重叠，
见 §4.3），不经过脑连接这条路径。DAG 结构为：

```
         ┌──────────── c = +0.258 ────────────┐
         │                                    ▼
   SDQ 多动量表 ── a = −0.067 ──▶ 连接模式 ── b = +0.023 ──▶ ADHD 诊断
        (X)                        (M)                        (Y)
                                  ▲ ▲
                                  └─┴── 年龄（混淆 C，虚线）
```

### 5.7 小结

六项检验从六个角度一致地回答了研究问题：**连接矩阵里确实存在一点微弱的
独立信号**（偏相关 0.536、图论特征 0.527、GCN 0.555，都略高于随机），
但它既不能单独分类（都远低于问卷的 0.84），也**不是**问卷→诊断的中介。
「独立于问卷的判别信号」的答案是有、但很小——在问卷之上仅有 +0.01～0.02
的增量，且显著性有限。

---

## 6. 结论

1. **行为问卷与 ADHD 标签高度相关（AUC 0.84），但该相关主要是定义性的**
   ——SDQ 多动量表与诊断标准构造重叠，不能据此宣称发现了病因；中介分析
   （§5.6）进一步证实这条强相关**不经过**「脑连接模式」这一中介路径。
2. **功能连接矩阵里只有微弱的独立信号**：单独 AUC ≈ 0.51–0.56（GCN、
   偏相关、图论特征），在问卷之上仅有 +0.01～0.02 的增量；图结构相对
   扁平特征的 +0.05 差距方向稳定（§5.1 bootstrap）。
3. **方法上，本报告的价值在于把「连接矩阵到底有没有用」做成了可验证的
   结论**：subject-level 切分防泄漏、加权 F1 处理类不平衡、水位基线定位
   信号来源、bootstrap 检验增量显著性、偏相关与图论特征排除「方法没选对」
   的替代解释、中介分析区分「预测」与「机制」、SHAP 归因明确为预测贡献
   而非因果效应。

一句话收束：**功能连接是关联的载体，不是机制的证明；预测做得好，
不等于因果讲得通。** 一份诚实的统计报告，首先应写清这条边界——本报告
用六项检验把这条边界从「判断」变成了「可复现的结论」。

## 附录 A · 指标定义

| 指标 | 定义 | 何时用 |
|---|---|---|
| 准确率 | 预测正确的占比 | 类别平衡时 |

| balanced accuracy | 敏感度与特异度的均值 | 类不平衡时的准确率替代 |
